# 旧版原生 MIDI 实验

此目录保存规则引擎的历史示例，不代表当前音频工作台或 Mureka 的音乐效果。保留数据是为了复现和验证旧快照兼容性。

- `demo/`：schema 1 的前后版本、MIDI 与参考 WAV；JSON 快照由兼容性测试读取。
- [creative_v2/](creative_v2/README.md)：schema 2 的 A/B/C 编曲与局部编辑示例，含逐轨差异。

WAV 使用简单参考合成器生成；它们不是成品混音。使用说明见 [原生 MIDI](../../docs/NATIVE_MIDI.md)。当前产品案例见 [showcase](../showcase/README.md)。
