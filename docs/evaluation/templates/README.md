# 人工音质评价模板

A/B/C.json 是尚未执行的评价表，保存示例输入与待填写的结果字段。空值和 `NOT_RUN` 是模板状态，不是产品演示或生成成功报告。

运行方式见 [真实 smoke](../../AUDIO_API.md#真实-smoke-与人工试听)。每条新生成都可能付费；不要自动批量运行。已有音频可以直接填写文件来源与评价，无需重新生成。

建议分别记录：情绪符合度、声音质感、说唱空间、段落变化、纯伴奏人声残留、分轨串音，以及 MIDI 转录与原音频的差异。评价应由实际试听者填写；请求中的 BPM 和风格不能当作实测值。

当前真实案例见 [半杯常温与 Jazz Beat](../../../examples/showcase/README.md)。离线 Mock 输出只是 4 秒测试信号。
