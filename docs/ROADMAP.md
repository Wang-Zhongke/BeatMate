# Roadmap

[产品首页](../README.md) · [测试与验证](ACCEPTANCE.md)

BeatMate 当前版本为 Audio MVP 0.1.0，面向个人本机使用。代码已发布到 [GitHub](https://github.com/Wang-Zhongke/BeatMate)，[首轮 CI](https://github.com/Wang-Zhongke/BeatMate/actions/runs/35768225453) 已通过；后续提交状态以 [Actions](https://github.com/Wang-Zhongke/BeatMate/actions) 为准。

## 已实现

- 描述生成纯伴奏；完整歌词生成歌曲，获取整曲、伴奏、人声和供应商返回的 MIDI。
- 预览后确认提交、持久请求记录、查询与下载恢复；结果不确定时不自动重新提交。
- 本机配置与证书检查、DNS/TCP/TLS 连接诊断、版本更新提示。
- 曲库搜索、收藏、重命名、分页、回收站与恢复；跨页保留当前播放。
- A/B 音轨比较、片段循环、时间点备注、本地原文件打包导出。
- Python、前端模块和 Chromium 浏览器离线回归；macOS / Ubuntu CI。
- [真实作品案例](../examples/showcase/README.md)与独立 Mock 界面演示。

## 接下来

| 优先级 | 方向 | 验收目标 |
| --- | --- | --- |
| P1 | 真实音频波形与片段定位 | 波形来源于音频数据；键盘与手机均可选取循环片段 |
| P1 | 人工音质评价 | 用统一标准记录人声残留、分离串音、段落结构与 MIDI 转录问题；不以测试通过代替听感 |
| P1 | 前端职责继续拆分 | 创作表单、曲库和播放器分模块维护，现有回归持续通过 |
| P1 | 配置与草稿体验 | 明确保存状态与数据位置，支持命名草稿；密钥始终留在后端 |
| P2 | 网络恢复与代理支持 | 只在确认 HTTP 尚未发送时评估连接回退，不改变结果不确定时禁止重发的规则 |
| P2 | BPM、调性和响度检测 | 区分实测结果、置信度与创作请求值 |

更多供应商、细分轨、MIDI 编辑和桌面打包需要独立设计与质量验证。多用户云端部署、公网服务和完整 DAW 工程不属于当前版本范围。
